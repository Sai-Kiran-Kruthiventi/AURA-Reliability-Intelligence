# AURA — Autonomous Unified Reliability & Anomaly Intelligence

AI-powered component reliability intelligence platform for detecting,
investigating, predicting, and explaining anomalies during component
burn-in and screening.

## Project Structure

- frontend/ — Dashboard and visualization
- backend/ — APIs and system integration
- ai/ — ML models
- data/ — Data processing and simulation
- agents/ — AI agents
- rag/ — Engineering knowledge retrieval
- knowledge_graph/ — Component relationships
- tests/ — Testing
- docs/ — Project documentation
